# Chatbot Projects Collection

This repository contains a series of Python chatbot projects that demonstrate the progression from simple chatbots to more advanced conversational AI systems. Each project showcases different functionalities and techniques, helping learners and developers understand how chatbots can be built and improved over time.

## Projects Included

1. **Basic Chatbot**  
   A simple chatbot built from scratch to demonstrate basic conversational logic and user interaction.

2. **Web Scraping Chatbot**  
   A chatbot that can answer questions based on information scraped from a webpage. Uses OpenAI APIs to generate context aware responses from web data.

3. **Conversation History Chatbot**  
   A chatbot that maintains conversation history, allowing it to provide responses that consider previous questions and answers for more context aware interactions.
